# Домашнее задание 2: Git

32 задачи выполняются в локальных Git-репозиториях. [Условия задач](TASKS.md) и [порядок задач](catalog.json) находятся в этом репозитории. Сайт для работы не нужен.

Нужны Git и Python 3.10 или новее. На Windows используйте WSL с установленными Git и Python. Docker студенту не нужен.

## Как начать

1. На странице этого репозитория нажмите **Use this template → Create a new repository**. Создайте **публичный** репозиторий в своём аккаунте GitHub. Не отправляйте изменения в общий шаблон.
2. Склонируйте свой репозиторий и перейдите в его корень.
3. Выполните `python3 hw2.py init`. Появится каталог `workspace/` с отдельной папкой для каждой задачи.

Комплект привязан к адресу вашего GitHub-репозитория (`origin`). Не переименовывайте его и не меняйте `origin` во время работы: проверка сдачи сверяет этот адрес.

Например, первая задача лежит в `workspace/01_setup/`. Номер в командах ниже — номер из [списка задач](TASKS.md), а не внутренний ID в каталоге.

## Работа и проверка

Работайте с файлами и Git-репозиториями внутри `workspace/`. Проверяйте задачу командой:

```sh
python3 hw2.py check 1
```

Проверка читает полное состояние задачи, включая индекс, рабочие файлы и локальную историю Git. Она выполняется на временной копии: ваши рабочие файлы не меняются. Результат — «зачтено» или «пока не зачтено»; готовый ответ не выводится.

Работу можно продолжать и проверять повторно. Проверяются результаты, а не конкретные команды, которыми вы их получили.

## Сдача

Для каждой задачи, которую хотите отправить, выполните:

```sh
python3 hw2.py submit 1
git add .hw2/manifest.json submissions/
git commit -m "Submit Git homework"
git push
```

`submit` создаёт архив в `submissions/`. В него попадают также `.git`, незакоммиченные изменения и локальный учебный `remote.git`: обычный `git push` этих состояний не передаёт. Можно сдавать задачи постепенно и повторять `submit` после исправления. Команда `submit` сохранит и незачтённый вариант, если вы хотите показать попытку. Чтобы заменить уже сохранённый архив незачтённой попыткой, понадобится явный флаг `--force`.

**Перед публикацией проверьте, что не добавили в учебные репозитории секреты или личные файлы.** Архив содержит полную историю Git, включая `.git/config`, reflog и объекты удалённых коммитов. Не указывайте токены в URL remote. Для учебных коммитов используйте не личную почту, а адрес из условий задачи.

Отправьте преподавателю ссылку на **свой публичный репозиторий GitHub**. Не удаляйте его и не делайте приватным до завершения проверки. Время сдачи и конкретную ревизию репозитория фиксирует преподаватель.

`workspace/` намеренно не добавляется в внешний репозиторий: коммитить нужно архивы в `submissions/`. Репозитории внутри задач — учебные; их `origin`, если он есть, указывает на соседний локальный `remote.git`, а не на GitHub.

## Если компьютер сменился

Склонируйте свой GitHub-репозиторий и снова запустите `python3 hw2.py init`. Файл `.hw2/manifest.json` хранит параметры именно вашего комплекта задач, а сохранённые архивы из `submissions/` будут развёрнуты обратно в `workspace/`. Отправляйте архивы на GitHub регулярно: изменения только в `workspace/` останутся на прежнем компьютере.

Итоговую проверку преподаватель повторит независимо по присланным архивам. Изменение локального проверяющего кода не меняет результат сдачи.

## Преподавателю

Проверяйте зафиксированный на момент дедлайна коммит студенческого репозитория. Скрипт `grade.py` и контейнер собирайте **из доверенной копии этого шаблона**, не из присланного репозитория. Адрес репозитория передавайте независимо от файлов студента: `--repository OWNER/REPO`. Проверка не запускает студенческий `hw2.py` и читает только манифест и архивы отправок.

Из корня доверенной копии соберите образ: `docker build -t hw2-grader -f Dockerfile.grader .`. Затем проверьте отдельный checkout студента:

```sh
docker run --rm --network=none --read-only \
  --tmpfs /tmp:rw,nosuid,nodev,size=256m \
  --cap-drop=ALL --security-opt=no-new-privileges \
  --pids-limit=128 --memory=1g --cpus=1 \
  --mount type=bind,src=/ABS/STUDENT_CHECKOUT,dst=/student,readonly \
  hw2-grader /student --repository OWNER/REPO --json
```

Замените абсолютный путь и `OWNER/REPO` на checkout и адрес того же репозитория GitHub. Повторять проверку на доверенной копии нужно для каждого студента; запускать код из присланного репозитория нельзя. Совпадение решений между студентами этот чекер не определяет — для проверки на списывание нужен отдельный анализ архивов.
